# Week 11 - Tutorial 11

## Computer Lab Access System

This project is developed using Python modular programming.

### Files

- main.py
- student.py
- access.py
- display.py

### Description

The system checks whether a student is allowed to enter the computer laboratory.

The program verifies:

- Student registration
- Lab availability
- Computer availability

If all conditions are satisfied, access is granted.

Otherwise, access is denied with an appropriate reason.
